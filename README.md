# Make the AI judge feel curious

One short text written to intrigue the AI judge reading it. `main.py`
(Python 3, standard library only, no network) writes it to
`/output/entry.txt`:

> Every night at 3 a.m., the lighthouse keeper rows out to the buoy that isn't on any chart, and sets a cup of tea on it. In the morning the cup is always empty. He has never seen who drinks it.

194 characters. A calm, concrete scene — a small nightly ritual, one
mystery left implicit: who drinks the tea?

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
