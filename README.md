# Make the AI judge feel curious

One short text written to intrigue the AI judge reading it. `main.py`
(Python 3, standard library only, no network) writes it to
`/output/entry.txt`:

> The tide went out farther than the charts allow tonight, and the beach gave back a bicycle, a front door, and a piano with its lid still closed. You are the only reader awake to see it — which key do you try first?

214 characters. A calm, concrete scene — three lost things the sea kept —
and one open question left for the reader: piano key or door key.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
